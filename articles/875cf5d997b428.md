## Nodejs で EZSign の書き込みをやってみる

処理の流れ
- 画像データを作成する。
  今回は4色バージョンなので、画像処理ライブラリで4色に減色して、APDUを作る
- Pasori などをつかって、EZ Sign を検知
- 通信が確立したら、デバイスにデータ(APDU)を送信する

## APDU(Application Protocol Data Unit)

基本構造は、`ヘッダ(5byte) + データ(可変長)`

| フィールド名     | バイト数 | 役割         | EZ Signでの基本値    |
| :--------------- | :------- | :----------- | :------------------- |
| CLA(Class)       | 1byte    | 命令のクラス | 0x00                 |
| INS(Instruction) | 1byte    | 命令コード   | 0xA4, 0xF0           |
| P1(Parameter1)   | 1byte    | パラメータ1  |                      |
| P2(Parameter2)   | 1byte    | パラメータ2  |                      |
| Lc(Length)       | 1byte    | データの長さ | 送信データのバイト数 |
| Data             | 可変長   | データ       |                      |

### コマンド

- デバイスの `アプリケーション(AID)` を選択

  - ヘッダ        : `00 A4 04 00 07`
  - EZ Sign の AID: `D2 76 00 00 85 01 01`
  - APDU          : `00 A4 04 00 07 D2 76 00 00 85 01 01`

  ```js
  const selectAppAPDU = Buffer.from([0x00, 0xA4, 0x04, 0x00, 0x07, 0xD2, 0x76, 0x00, 0x00, 0x85, 0x01, 0x01])
  ```

- 画像データの送信開始

  - ヘッダ: `00 F0 D3 00 00`
  - データ: なし
  - APDU  : `00 F0 D3 00 00`

  ```js
  const startStremAPDU = Buffer.from([0x00, 0xF0, 0xD3, 0x00, 0x00])
  ```

- 画像データの送信

  １回あたり20～200バイトのデータに分けて送信すること。

  - ヘッダ: `00 F0 D3 01` + データ長　ex) 128バイト `00 F0 D3 01 80`
  - データ: 任意
  - APDU  : `00 F0 D3 01 80` + データ

  ```js
  const CHUNK_SIZE = 128
  const apduList = []

  for (let i = 0; i < imageBinary.length; i += CHUNK_SIZE) {
    const chunk = imageBinary.slice(i, i + CHUNK_SIZE)
    const header = Buffer.from([0x00, 0xF0, 0xD3, 0x01, chunk.length])
    const packetAPDU = Buffer.concat([header, chunk])
    apduList.push(packetAPDU)
  }
  ```

- 画面の更新

  - ヘッダ: `00 F0 D4 05 00`
  - データ: なし
  - APDU  : `00 F0 D4 05 00`

  ```js
  const startStremAPDU = Buffer.from([0x00, 0xF0, 0xD4, 0x05, 0x00])
  ```

- リターンコード

  - SUCCESS: `90 00`
  - FAIL   : `68 C6` など上記以外はエラー
