## MediaMTX

MediaMTX とは。

すぐに使用可能な、依存性なしのライブメディアサーバかつメディアプロキシです。
リアルタイム映像音声ストリームを発信・読み込み・録画・再生します。
"メディアルータ"と考えてよく、効率と可搬性を重視してある場所から異なる場所へメディアストリームをルーティングします。

主な特徴:

- `Publish`: 以下の手段でサーバへライブストリームを配信
  - Media-over-QUIC
  - SRT
  - WebRTC
  - RTSP
  - RTMP
  - HLS
  - MPEG-TS
  - RTP
  - FFmpeg
  - GStreamer
  - OBS Studio
  - Python
  - Golang
  - Unity
  - Web browsers
  - Raspberry Pi Cameras

- `Read`: サーバからライブストリーミングを受信
  - Media-over-QUIC
  - SRT
  - WebRTC
  - RTSP
  - RTMP
  - HLS
  - FFmpeg
  - GStreamer
  - OBS Studio
  - Python
  - Golang
  - Unity
  - Web browsers

- Streams: ストリームは自動的にあるプロトコルから別のプロトコルへ変換される

- Serve: 同時に異なるパスで複数のストリームを供給する

- Reload: 既存のクライアントの接続を切断せずに設定をリロードする（ホットリロード）

- Serve: 送信側がオフラインであっても、常時使用可能なストリームを供給する

- Record: MP4 あるいは MPEG-TS 形式でストリームをディスクへ録画する

- Playback: 録画されたストリームを再生する

- Authenticate: ユーザ認証（内部認証・HTTP認証・JWT認証）

- Forward: 別のサーバへストリームを転送する

- Proxy: 他のサーバへリクエストを代理する

- Control: 制御 API を使ったサーバの制御

- Extract: サーバからオープンソースのモニタリングソフト Prometheus 互換形成機でメトリクス（使用率などの情報）を抽出

- Monitor: CPU やメモリの消費を調査するためのパフォーマンスモニタ

- Run hooks (実験的なコマンド): クライアント接続・切断時や、ストリームの表示または発行時に、フックを実行

- Compatible: Linux, Windows, macOS で動作する。依存するものやインタプリタは不要。単一の実行ファイル。
